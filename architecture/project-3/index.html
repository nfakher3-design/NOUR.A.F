03 — Architecture

Residential Neighborhood Planning

Al-Nabk, Rif Dimashq

Year

2025

Location

Al-Nabk, Rif Dimashq

This project presents an urban planning proposal for a residential neighborhood in Al-Nabk, developed in response to the area's current conditions and challenges.

The design applies core urban planning principles to organize residential blocks, circulation networks, and shared public spaces, aiming to create a functional and livable neighborhood that responds to the site's existing context.
